# コンテキスト資料の目次

この `docs/context/` は、人や別のAIがこのプロジェクトの作業を引き継ぐときに、最初に読む資料です。
**新しいセッションでは、まず `05_引継ぎ_次の作業.md` を読んでください。**
それぞれ単独で読めるように書いています。

| ファイル | 内容 | 読む場面 |
|---|---|---|
| `01_機能要件.md` | 元の要件定義の機能要件（ID付き）と、それぞれの実装・検証の状況 | 何を作ったか、何が残っているかを知りたい |
| `02_非機能要件.md` | 操作性・安定性・セキュリティなどの非機能要件と、満たし方・根拠・未確定の点 | 品質の根拠を知りたい |
| `03_現状.md` | 2026年10月19日時点の状況、検証結果、人の判断待ち、既知の問題、動かし方 | いま何がどうなっているかを知りたい |
| `04_追加機能と変更履歴.md` | 元の要件に無かったが追加した機能と、開発の経過（ハーネス・ペルソナ評価・修正） | なぜそうなっているかを知りたい |
| **`05_引継ぎ_次の作業.md`** | **作業の前提（依頼者の好み・守ること）、2026-10-19 に決まったこと、次の作業の案、依頼者に確かめること** | **新しいセッションで最初に読む** |
