## 2. 実装の進め方の案（**未決定**。依頼者に確かめてから進める）

### 2.1 住民の予約を止める
- スクリプトプロパティなどの設定で「住民の予約を受け付けるか」を切り替える。既定は「受け付けない」。
- サーバー：`api_submitReservation` は、受け付けないときに状態を変えず、不成立（理由：受付していない）を返す。画面を消すだけでは不十分で、公開関数は誰でも直接呼べるので、**サーバーで止めることが本体**。
- **注意（ハーネスとの衝突）**：受入試験（保護）の多くは、住民の申込みが確定することを前提にしている（U-04、競合・再送・通信断など）。そこで、試験環境では `contract/adapter.js` の setup で受付を「開く」に設定し、本番の既定は「閉じる」にする案が考えられる。あわせて、「閉じているときに確定しない」試験を `tests/impl/` に追加する。この扱いは、DECISIONS に書いてから進める。
- 管理者の代行登録（電話・窓口）は今のまま使える。

### 2.2 住民の画面を月表示・台数なしに
- 今の週の表（日付×朝・昼・午後・夜）を、月のカレンダーにする。
- 1日の中の4コマの空きを、台数を出さずに示す。たとえば日ごとに4つの小さな ○／× を並べる。形は依頼者に見せて決める。
- 「予約の確認」（予約番号と電話番号の下4けた）を残すかは、依頼者に確かめる。管理者が電話で登録した予約の確認には使える。
- 申込みのフォーム・確認・結果の画面は、消すのではなく**出さない**形にしておくと、あとで開放しやすい。

### 2.3 管理者の表示
- 今：PC は1週間の予約表（日付×時間帯×区画の12列）、スマホは日付の札と1日の表。
- 月表示にする場合の案：月のカレンダーで日ごとの埋まり具合を見せ、日を押すとその日の表を出す。週の表と切り替えられる形もある。**見やすさを依頼者と詰めてから作る**。

### 2.4 使用禁止・予約不可
- 台帳に「使用禁止」シートを足す案。列は、日付、コマ（空なら終日）、駐車場（空なら全区画）、理由、登録者、登録日時。期間で指定するなら、開始日と終了日も持つ。
- 空き状況・確定処理・区画の割当ての全てで、禁止された枠を数から除く。確定処理（ロックの中）でも必ず確かめる。
- すでに予約がある枠を禁止にしようとしたときの扱いは、依頼者に確かめる。自動で取り消さず、該当する予約を一覧で示す案。
- 画面：管理者の予約表で、日・コマ・区画を選んで「使用禁止にする」「解除する」。表では網かけなど、受付時間外とは区別できる見た目にする。操作履歴に残す。

### 2.5 台帳をスプレッドシートで触らない
- 今でも、予約の登録・取消し・電話連絡の記録は、全て管理者画面から行える。
- 足りないもの：使用禁止の設定（2.4）、指定の形の印刷（2.6）、ルールの変更（受付期間・料金など。今はスクリプトプロパティ `RULES`）、管理者の追加・パスコードの再設定（今は `docs/SETUP.md` の手作業）。どこまで画面にするかは依頼者に確かめる。

### 2.6 指定の形の印刷
- **依頼者から、指定の形（今使っている紙の様式など）を受け取る必要がある**。受け取ったら、印刷用の画面（`@media print` か、印刷用の別表示）を作る。
- 今の印刷は、予約表をそのまま印刷するだけ。

## 6. 手元のスクショで丸ゴシックを出す方法

```bash
cd <作業用の場所> && npm pack @fontsource/zen-maru-gothic && tar xzf fontsource-zen-maru-gothic-*.tgz
pip install --break-system-packages fonttools brotli
# package/files の woff2（太さ400・500・700）を、太さごとに1つの ttf にまとめて ~/.fonts に置き、fc-cache -f
```

まとめるスクリプトの例：fontTools の `Merger` で、`zen-maru-gothic-*-{太さ}-normal.woff2` を ttf にしてから結合する。
